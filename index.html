About & provenance

Brainchurn implements general, non-proprietary creativity techniques (problem framing, divergent association, lateral provocation, morphological combination, weighted evaluation, contradiction-resolution heuristics). It contains no third-party word database and reuses no copyrighted text. The optional "Open data" engine queries the free Datamuse API live; the "AI bridge" uses your own AI; "Offline" uses only your input. Working name "Brainchurn" is a placeholder pending a trademark search. Not affiliated with any existing product.
